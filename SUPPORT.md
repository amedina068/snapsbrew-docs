# Get help with the Snapsbrew docs

One person maintains Snapsbrew and its documentation. Answers to questions, issues and pull requests are not immediate. Use the correct place for each request, so that the maintainer can find it.

## Read the documentation

The published documentation is at [snapsbrew.com/docs](https://snapsbrew.com/docs). For a problem with an instance, read the [troubleshooting page](https://snapsbrew.com/docs/self-hosting/troubleshooting) first.

## Ask a question

Ask a question in the [Q&A category of the Discussions](https://github.com/amedina068/snapsbrew/discussions/categories/q-a) of the app repository. Do not open an issue for a question.

## Report an error in the docs

If a page is not correct, or if a page is missing, open an [issue in this repository](https://github.com/amedina068/snapsbrew-docs/issues/new/choose) with the matching form.

If the problem is in the app and not in the docs, open an [issue in the app repository](https://github.com/amedina068/snapsbrew/issues/new/choose).

## Report a security problem

Do not open a public issue or a discussion for a security problem. Read [SECURITY.md](SECURITY.md).
