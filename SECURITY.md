# Security policy

## A security problem in Snapsbrew

This repository holds the documentation only. A security problem in the Snapsbrew app, its API, its MCP server or its Docker image belongs to the app repository.

Do not open a public issue for a security problem. Report it in private through a [GitHub security advisory of the app repository](https://github.com/amedina068/snapsbrew/security/advisories/new). Read the [security policy of the app](https://github.com/amedina068/snapsbrew/blob/main/SECURITY.md) for the details to give and the scope.

## A security problem in the docs

Some problems are in the docs site itself, for example a script injection through a page, or a page that shows a real token or key. Report such a problem in private in this repository:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

One person maintains this project, so answers are not immediate.

## A wrong security instruction

If a page gives a security instruction that is not correct, but the error is not secret, open an issue with the "Error in the docs" form.
